## PG_CONN — unchanged from round 2, restated

Its default is credential-bearing (interpolates `PG_PASSWORD`) and this repo is a public
mirror shipping placeholder values only. `.env.example`'s `PG_CONN` line (already added,
see note below) is a placeholder **shape** — `PG_CONN=postgresql://USER:PASSWORD@HOST:5432/DBNAME`
— never the interpolated real form, and T1's default-value assertion explicitly exempts
it (presence-only), with the reason written into the test itself.
